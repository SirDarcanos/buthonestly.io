# Domain Docs

This repository uses a single domain context.

Before exploring or changing the repository:

1. Read `CONTEXT.md`.
2. Read relevant decisions under `docs/adr/`.
3. Use the canonical terms from `CONTEXT.md`.
4. Surface conflicts with an ADR instead of silently overriding it.

If a domain document is absent, proceed silently. Domain documents are created lazily when terminology or architectural decisions are resolved.
