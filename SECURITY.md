# Security Policy

## Supported version

The current production deployment from `main` is the only supported version.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/SirDarcanos/buthonestly.io/security/advisories/new). Do not disclose a suspected vulnerability in a public issue.

Include the affected URL or dependency, reproduction steps, impact, and any known mitigation. You should receive an initial response within seven days.
